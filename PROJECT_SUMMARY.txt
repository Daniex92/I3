🗄️ DATABASE SCHEMA
================================================================================

TABLES (7):
  1. users
     - id (PK), username (UNIQUE), email (UNIQUE), password, role, timestamps
  
  2. categories
     - id (PK), name (UNIQUE), description
  
  3. subcategories
     - id (PK), category_id (FK), name, description
  
  4. products
     - id (PK), subcategory_id (FK), name, description, price, stock, image_url, timestamps
  
  5. orders
     - id (PK), customer_*, subtotal, shipping_cost, total_price, status, timestamps
  
  6. order_items
     - id (PK), order_id (FK), product_id (FK), quantity, unit_price
  
  7. settings
     - setting_key (PK), setting_value, updated_at

INDEXES:
  - products: subcategory_id, price, created_at
  - orders: status, created_at

DEFAULT DATA:
